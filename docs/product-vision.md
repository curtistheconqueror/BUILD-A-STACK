## The three doors (one coherent product)

```
🚀 START          📖 LEARN            🔧 BUILD
─────────         ────────            ────────
Fast-track        Glossary            Sandbox challenges
Get moving        Pull depth          Hands-on proof
60 seconds        when you want it    you get it
```

These aren't competing features. They're **three moments in one journey:**

1. **🚀 Start** — the front door. Gets someone moving immediately. Zero fluff.
   Shortest path from zero to an agent doing real work.

2. **📖 Learn** — depth they pull on when curious.
   Every term: *what it is → how the real stack uses it → pragmatic vs. production tradeoff.*
   Nobody is forced to read 200 terms. They tap the word they got stuck on.

3. **🔧 Build** — the hands-on proof. Wire it yourself.
   A piece that doesn't fit bounces back. Complete the branch and the data flow lights up.

## The anti-fluff edge

Other educators bury the core idea in hours of theory.
Build-a-Stack's rule: **60-second read, 5-minute do.**

The glossary isn't the enemy of brevity — it's *pull, not push.*
Fast-track stays ruthlessly short. Glossary sits underneath as reference.
**Brevity up front. Depth on demand.** That's the design.

## The AI assistant

Not a chatbot bolted on — the **connective tissue** that makes it feel alive.

| Where | Job |
|---|---|
| 🚀 Start | "Stuck? Here's your next move." |
| 📖 Learn | "What's a webhook?" → pulls the card |
| 🔧 Build | "Why won't this connect?" → hints |

One assistant, threaded through the whole journey.
Ships in phases: scripted guide first → real LLM brain later.
(And the upgrade from scripted → LLM *is itself* a Build-a-Stack lesson.)

---

## The "cube entity" principle (for the real stack)

If an LLM agent is added to the trading stack, it enters as an **advisory-only cube entity:**
- Observes, reasons, reports
- Never places trades
- Its calls are logged and compared to outcomes
- Bad call costs nothing; signal quality is measurable before granting more responsibility

This is the "know your debt" pattern Build-a-Stack already teaches — applied to itself.
